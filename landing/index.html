Common questions

Which file formats does Bind it accept?

MP3, M4A, M4B, AAC, WAV, FLAC and WMA. The output is a single M4B with chapter markers, cover art and metadata — or an MP3 if every input is MP3 and you keep the original codec.

Does Bind it work offline?

Yes. Everything runs locally. No account, no uploads, no network calls during binding.

Are Intel Macs supported?

The macOS build is universal — Apple Silicon and Intel are both covered.

Does it handle DRM-protected audio files?

No. Audible .aax and iTunes .m4p files are not accepted file types, and anything still encrypted cannot be decoded. Bind it works on unprotected files you already own — it does not remove protection.

How are chapters detected?

Chapter titles come from filenames by default. You can edit names, order and durations in the review step before binding.

Where does the output file go?

You pick the destination when you bind. Bind it never touches the source files.
