Features

Built for long-form audio.

Bind it reads the codec of every file and picks the fastest route: remux when it can, transcode only when it must.

  • Zero setup

    ffmpeg and ffprobe ship inside the app. Download, open, bind — there is nothing else to install.

  • Lossless remux

    AAC files are joined without re-encoding. Near-instant, and bit-for-bit identical to the source.

  • Parallel transcoding

    MP3 and mixed-codec sets convert across every CPU core at once. Hours of audio in minutes.

  • Chapters and metadata

    Title, author and cover art are read from your files and stay editable. Every input becomes a chapter marker.

  • Drag and drop

    Drop a folder to pull in everything inside it, then drag rows to fix the order before you bind.

  • Offline and private

    No uploads, no accounts, no telemetry. Your files never leave the machine, and sources are never modified.

How it works

Three steps, one file.

  1. 1

    Drop

    Drag in files or a whole folder. Bind it orders them by filename.

  2. 2

    Review

    Rename chapters, drag to reorder, set the title, author, cover and bitrate.

  3. 3

    Bind

    Choose where it lands. One M4B comes out, chapter markers included.

FAQ

Common questions.

Which formats can I feed it?

MP3, M4A, M4B, AAC, WAV, FLAC and WMA. The output is a single M4B with chapter markers, cover art and metadata — or an MP3 if every input is MP3 and you choose to keep the original codec.

Does it work offline?

Yes. Everything runs locally and there is no network call at any point — no account, no uploads, no telemetry.

Are Intel Macs supported?

Yes. The macOS build is universal, so one download covers both Apple Silicon and Intel, on macOS 11 or later.

How are chapters named?

Each input file becomes one chapter, titled from its filename. You can rename chapters and drag them into a different order before binding.

Does it handle DRM-protected files?

No. Bind it only processes unprotected audio files that you already own.

What happens to my original files?

Nothing. You choose a destination for the new file, and the sources are left exactly as they were.
